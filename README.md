# CardioTwin

**Explainable 3D coronary-risk digital twin** — predicts overall coronary artery disease (CAD) and
vessel-level stenosis (LAD · LCX · RCA) from routine clinical data, explains every prediction with SHAP,
and maps the risk onto a real, interactive 3D human heart built from BodyParts3D anatomy.

> ⚠️ Decision-support / educational prototype only — **not** a substitute for formal diagnostic imaging.
