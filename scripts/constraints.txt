# Exact versions of every package the CardioTwin Python environment resolves to (Python 3.11, CPU only),
# so installs are reproducible down to transitive dependencies. Used as a pip constraints file by
# scripts/dev.*, CI (.github/actions/setup-python-env) and the Docker image:
#   python -m pip install -r backend/requirements.txt -c scripts/constraints.txt
#   python -m pip install -r scripts/requirements-dev.txt          (includes `-c constraints.txt`)
# Direct pins that live next to their package are not repeated here: the ML stack and its test tools in
# ml/requirements.txt (the versions the published artifacts were built with), the anatomy QA and lint tools in
# scripts/requirements-dev.txt. A constraint only applies when something requires the package, so the
# platform-specific entries (colorama on Windows, uvloop elsewhere) are harmless on the other platform.
# Every pin below has a CPython 3.11 wheel for Windows x64 and manylinux x86_64 (no source builds).
