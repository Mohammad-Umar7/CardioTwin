# Model card — CardioTwin coronary-risk models v1.1.0

Format follows Mitchell *et al.*, "Model Cards for Model Reporting" (FAT* 2019). All numbers are generated by
`python -m cardiotwin_ml.train` and can be checked in [`ml/artifacts/metrics.json`](../ml/artifacts/metrics.json) and
[`ml/reports/results.md`](../ml/reports/results.md).

> **Clinical safety.** CardioTwin is a research and educational decision-support prototype. Its outputs are **not a
> diagnosis** and are **not a substitute** for coronary angiography, CT coronary angiography, functional testing or
> clinical judgement.

## 1. Model details

| | |
| --- | --- |
| **Developers** | CardioTwin project (Multimodal AI Hackathon 2026, Track A) |
| **Version / date** | 1.1.0, September 2026 (see §11 for the changes from 1.0.0) |
| **Type** | Four binary classifiers, one per target: overall **CAD** (≥ 1 major coronary artery with ≥ 50 % diameter stenosis) and vessel-level stenosis of the **LAD**, **LCX** and **RCA** |
| **Architecture** | Per target: margin-space ensemble `m = w·m_LR + (1−w)·m_XGB` of a regularised logistic regression and an XGBoost model, Platt-calibrated `p = σ(a·m + b)`, Youden-J decision threshold |
| **Inputs** | 53 routine clinical variables (demographics, risk factors, symptoms, examination, resting ECG, laboratory, transthoracic echo). Angiography results (`LAD`, `LCX`, `RCA`, `Cath`) are **never** inputs |
| **Explanations** | Exact SHAP values in log-odds space (linear SHAP + float64 path-dependent TreeSHAP, combined linearly), additive to < 1e-14; also reported on the calibrated log-odds scale (`shap_calibrated` = Platt slope × SHAP) so contributions add up to the displayed probability |
| **Software** | Python 3.11, scikit-learn 1.9.1, XGBoost 3.2.0; portable JSON model evaluated identically in Python and the browser |
| **Licence** | Code MIT; data CC BY 4.0 (UCI); see `NOTICE.md` |

Deployed components (hyper-parameters tuned on the development set only, by log-loss):

| Target | Logistic component | w (LR) | XGBoost | Platt (a, b) | Threshold (Youden) |
| --- | --- | --- | --- | --- | --- |
| CAD | elastic net (C = 0.318, l1 ratio 0.69), all features | 0.40 | 108 trees, depth 2 | 1.284, −0.207 | 0.747 |
| LAD | L1, C = 0.133, all features | 0.55 | 290 trees, depth 3 | 1.278, 0.080 | 0.551 |

The logistic variant (L2 / L1 / elastic net / clinical core) was chosen per target by nested-CV ROC-AUC; the
XGBoost component always uses all features. Weight, Platt parameters and threshold are fitted on out-of-fold margins
of components with exactly these hyper-parameters, so the calibration map matches the deployed margin scale (Platt
slopes close to 1).

## 2. Intended use

* **Primary use:** interactive education and research demonstration — showing how routinely collected clinical
  data relate to angiographic coronary disease, and *why* a model assigns a given risk (per-feature SHAP), mapped
  onto a 3D heart at **vessel level**.
* **Intended users:** clinicians, students, researchers and hackathon judges exploring explainable cardiovascular
  risk modelling.
* **Setting:** adults with suspected coronary disease who are *already* being considered for coronary angiography
  (the population the data come from).

## 3. Out-of-scope uses

* **Diagnosis or triage of individual patients**, ruling coronary disease in or out, or deciding whether to perform
  angiography, revascularisation or any treatment.
* Screening of asymptomatic or general populations (the model never saw such patients; its 71 % CAD prevalence is
  far higher than in the community, so probabilities would be grossly miscalibrated).
* **Lesion localisation.** Predictions are per vessel. The 3D colouring of a vessel does not indicate where in the
  vessel a stenosis is, and echo `Region RWMA` is a wall-motion finding, not a lesion map.
* Acute coronary syndromes, patients with prior revascularisation or grafts, children, or any population outside
  the training data.

## 4. Factors

* **Relevant groups:** sex (58 % male), age 30–86 years, diabetes, hypertension. An exploratory subgroup analysis
  by sex, age band and diabetes (§8, *Subgroups*) is reported with CIs; at 61 test patients the test-set subgroup
  estimates are unstable, so the development-set out-of-fold estimates carry the signal. Vessel-level discrimination
  is lower in patients over 65 and in patients with diabetes.
* **Instrumentation:** single centre; laboratory assays, echo readers and ECG interpretation of one institution.
  Units follow the source paper (see `data/README.md`); some codings (functional class scale, `Region RWMA`,
  single blood-pressure value) are not documented by the dataset authors.

## 5. Metrics

Discrimination (ROC-AUC, PR-AUC), classification at the deployed threshold (accuracy, precision, recall/sensitivity,
specificity, F1, MCC, balanced accuracy), probabilistic accuracy (Brier score, log-loss), calibration (reliability
curve, ECE, calibration slope/intercept) and clinical utility (decision-curve net benefit). Test-set uncertainty:
2000 stratified bootstrap resamples, percentile 95 % CIs, threshold held fixed.

## 6. Evaluation and training data

* **Dataset:** *Extension of Z-Alizadeh Sani* (UCI id 411, DOI 10.24432/C5461K, CC BY 4.0): 303 consecutive patients
  referred for coronary angiography at one tertiary centre in Tehran; 55 candidate inputs, no missing values.
  Labels: CAD 216 / 303 (71 %), LAD 177, LCX 119, RCA 114 stenotic.
* **Split:** a **locked 20 % test set (61 patients)**, seed 42, stratified on the joint CAD/LAD/LCX/RCA label pattern;
  the remaining **242 development patients** were used for everything else.
* **Preprocessing:** `Y/N` and `0/1` unified, `Fmale → Female`, `BBB` one-hot, `VHD` ordinal. Columns constant in the
  development set are dropped: `Exertional CP` (constant in the whole dataset) and `CHF` (its only positive patient
  is in the test set). Imputation/scaling are fitted inside cross-validation folds.

## 7. Validation protocol

1. Development set: repeated stratified 5-fold × 10 cross-validation per target, identical folds for all models.
2. Nested tuning (inner stratified 5-fold `RandomizedSearchCV`, **log-loss**) for logistic regression (L2, L1, elastic
   net, clinical core), SVM, kNN and XGBoost; random forest, extra trees and histogram boosting use fixed settings.
3. Evidence-driven extras were tested on paired folds and **all rejected** (adoption bar +0.005 mean ROC-AUC):
   derived features (NLR, TG/HDL, risk-factor count, CKD-EPI eGFR) +0.0015, in-fold univariate selection −0.0065,
   classifier chain on out-of-fold CAD probability +0.0015.
4. The ensemble's CV estimate is **cross-fitted**: for every outer fold, the logistic variant, weight, Platt
   parameters and threshold are re-chosen on the other folds of that repeat, so no CV number below was used to make
   a choice it is scored on.
5. Deployed model: component hyper-parameters searched on the full development set; a 10 × 5 CV with those final
   hyper-parameters gives the out-of-fold margins on which the weight, Platt calibration and Youden threshold are
   fitted; components are then refitted on the full development set.
6. The test set was scored with the frozen models; only the deployed ensemble and the pre-specified clinical
   baseline were evaluated on it. The deployed models never saw a test patient, so all 61 test patients in the demo
   cohort are genuinely unseen. The test set has been scored twice in total — once per release (§11).
7. Descriptive validation analyses (`python -m cardiotwin_ml.analysis`; nothing in the deployed model depends on
   them): **robustness** — the complete recipe (hyper-parameter search, OOF weight/Platt/threshold, refit) re-run on
   200 random stratified 80/20 splits of all patients, validated by reproducing the deployed test probabilities bit
   for bit on the locked split; **modality ablation** — cumulative, leave-one-modality-out and single-modality feature
   sets on the development folds with Nadeau–Bengio corrected resampled t intervals and Holm adjustment;
   **subgroups** — sex, age band and diabetes on the cross-fitted development predictions and the test set.

The locked split is one of the hardest for CAD and LAD (the clinical baseline also lands at its 4th / 14.5th

### Explainability checks

Ensemble SHAP additivity error ≤ 1.8e-15 on the test set; float64 TreeSHAP vs XGBoost `pred_contribs` and the
`shap` 0.51 library ≤ 3.9e-7 (float32 precision of those references); portable (browser) model vs native Python
predictor ≤ 2.3e-16 in probability and identical SHAP on **all 303 patients** (and on 39 parity fixtures). Most
influential inputs (mean |SHAP|, dev set): typical angina for every target, then age; regional wall-motion
abnormality, ejection fraction and ESR for CAD/LAD; sex and diabetes for LCX/RCA.

## 9. Ethical considerations

* **Automation bias.** A confident-looking probability on a 3D heart can be over-trusted. The UI must keep the
  disclaimer visible, show uncertainty, and present explanations as associations, not causes.
* **Selection bias and transportability.** Patients were selected for angiography by clinicians, so the model
  learns "who among referred patients has stenosis". Performance and calibration in other populations, health
  systems or ethnic groups are unknown.
* **Label quality.** Stenosis ≥ 50 % by visual angiographic assessment is an anatomical, operator-dependent label, not
  a measure of ischaemia or outcome. One patient is labelled `Cath = Normal` despite a stenotic LAD; labels were
  used as published.
* **Privacy.** The dataset is public and de-identified; no additional personal data are collected by the model.
* **Fairness.** The exploratory subgroup analysis (§8) finds no systematic miscalibration by sex, age band or
  diabetes, but lower vessel-level discrimination in older and diabetic patients; the intervals are wide and no
  subgroup-specific threshold or recalibration was derived. Sex is an input, so predictions differ by sex by design
  (as in clinical pre-test probability scores).

## 10. Caveats and recommendations

* **Small, single-centre cohort (303 patients, 61 in test).** Test CIs are wide (e.g. LAD ROC-AUC 0.61–0.86).
* **Development-to-test gap.** CAD and LAD test ROC-AUCs are ~0.08–0.13 below their cross-fitted CV estimates; the
  clinical baseline drops by a similar amount (CAD 0.924 → 0.822, LAD 0.811 → 0.743), which points to a harder random
  test split rather than overfitting specific to the full model. The Monte-Carlo analysis (§8) confirms it: over 200
  random splits the locked split ranks at the 3rd (CAD) and 1.5th (LAD) percentile of held-out ROC-AUC, while the CV
  means sit mid-distribution. The same split makes CAD/LAD predictions look over-confident on test (slopes 0.62/0.47,
  at the 6th / 1.5th percentile of the Monte-Carlo slopes, whose medians are 1.02 / 0.97).
* **Limited added value per vessel.** On the locked test set the full clinical/ECG/lab/echo panel does not
  significantly outperform the 5-feature clinical baseline for any target (all paired CIs include 0). Across 200
  random splits it wins in 84 % (CAD) and 92 % (LAD) of splits but only 76 % / 69 % for LCX / RCA (mean ΔAUC +0.010 /
  +0.006), and in development CV the ECG, labs and echo add significantly only for CAD and LAD. Vessel-level (LCX, RCA)
  discrimination is modest (Monte-Carlo median ROC-AUC 0.76 / 0.75).
* **Thresholds** were chosen to balance sensitivity and specificity on development data (Youden's J); a clinical
  deployment would need thresholds chosen for its own costs of false negatives and false positives (see the
  decision curves in `docs/figures/decision_curves.png`).
* **Recommendation:** external validation on an independent, multi-centre cohort — and recalibration to the local
  prevalence — is required before any use beyond education and research.

## 11. Release history and independent review

The locked test set has been scored once per release. v1.1.0 follows an adversarial code review of v1.0.0; every
change below was specified and verified on the **development set only** before the test set was scored again, and no
feature, model family, search space or selection rule was changed in response to test results.

| Finding in v1.0.0 | Evidence (development set) | Change in v1.1.0 |
| --- | --- | --- |
| Platt scaling, ensemble weight and thresholds were fitted on nested-CV margins whose per-fold hyper-parameters differed from the deployed ones | RCA: deployed C = 0.0017 vs fold median 0.25; OOF margin sd 0.92 (nested) vs 0.35 (deployed hyper-parameters); the correct Platt slope was 2.5, the deployed one 0.96 | Weight, Platt and thresholds fitted on OOF margins of the deployed hyper-parameters |
| Ensemble CV metrics were computed on the same OOF predictions that selected the logistic variant, weight, calibration and threshold (optimistic; ensemble ranked first by construction) | Same tuning, cross-fitted estimate 0.002–0.011 lower per target (CAD 0.942 → 0.941, RCA 0.738 → 0.727) | CV metrics cross-fitted; ensemble no longer first for CAD and RCA |
| Tuning on ROC-AUC, which is almost flat in the regularisation strength, drove C to the edge of its range | Platt slopes 1.4–7.7; cross-fitted mean ROC-AUC 0.8178 (ROC-AUC tuning) vs 0.8171 (log-loss tuning), mean log-loss 0.5025 vs 0.4966 | Tuning by log-loss; Platt slopes now 1.03–1.28 |
